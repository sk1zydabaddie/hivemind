# Spec: Add greet helper
status: ratified
authored: drafted

## Goal

Create src/greet.js with a greet(name) helper that returns exactly "Hello, <name>!". Add focused coverage in test/greet.test.js.

## Non-goals

- Does not change any existing helper.

## Acceptance criteria

- greet("Ada") returns "Hello, Ada!".
- test/greet.test.js covers the helper and passes.
- npm test completes successfully.

## Assumptions

- The helper will use the module export style already used by this project.
- Names are interpolated as provided, without validation, trimming, or capitalization.

## What was asked for

Add a greet(name) helper in its own file src/greet.js that returns 'Hello, <name>!', with its own test file test/greet.test.js. Do not change any other file.
