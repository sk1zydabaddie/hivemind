# Spec: Add greet helper
status: ratified
authored: drafted

## Goal

Create `src/greet.js` with a `greet(name)` helper that returns exactly `Hello, <name>!`. Add focused tests in `test/greet.test.js` without modifying any other file.

## Non-goals

- Does not change any existing helper.

## Acceptance criteria

- `src/greet.js` exists and returns the exact greeting for a supplied name.
- `test/greet.test.js` verifies the helper’s exact output.
- `npm test` passes.
- Only the two requested files are added or changed.

## Assumptions

- `name` is expected to be a string and does not need trimming, escaping, or deliverability-style validation.
- The helper uses the module export convention already used by the project.
- Tests cover representative names while preserving the exact punctuation and spacing.

## Open questions

## What was asked for

Add a greet(name) helper in its own file src/greet.js that returns 'Hello, <name>!', with its own test file test/greet.test.js. Do not change any other file.
