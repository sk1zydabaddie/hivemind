  PIDs, both successful read-only observations, both refused conversation
  starts, the busy-project restart refusal, old and relaunched app process
  identities, and the expected/completed five-field artifact identities.

file it touched, stopped both fixture daemons, and removed both project
directories. It manually staged the already-admitted lease and pending marker
because Phase 11 owns lifecycle coordination only. It did not discover,
download, install, sign, or publish an update; those authorities remain absent
until R2 supplies an immutable admitted artifact.
