# Spec: Add shout helper
status: ratified
authored: drafted

## Goal

Add a `shout(text)` helper in `src/shout.js` that returns the input converted to uppercase with one exclamation mark appended. Add dedicated tests in `test/shout.test.js`.

## Non-goals

- Does not modify `package.json`, `src/capitalize.js`, or any other existing file.

## Acceptance criteria

- `npm test` passes.
- `src/shout.js` exists and `shout("hello")` returns `"HELLO!"`.
- `test/shout.test.js` exists and covers the helper's uppercase and exclamation-mark behavior.
- Only the two requested new files are changed or added.

## Assumptions

- The helper accepts a string input.
- An exclamation mark is appended unconditionally, so an input already ending in `!` receives another one.
- The project’s existing module and test conventions determine the export and import syntax.

## Open questions

## What was asked for

Add a shout(text) helper in its own file src/shout.js that returns the text in upper case with an exclamation mark, with its own test file test/shout.test.js. Do not change any other file.
