Verified, not claimed

Five coding agents were put through one capability contract. Four are adaptable and one is refused with a reason. The interesting result is that the two verdicts disagree: the only harness proven on real end-to-end work is the one that can never confirm the guarantee the product is built on.

The story in the table

Codex is the only harness with proven end-to-end runs — three tiers, real shipped commits, everything else measured against it. It is also the only one that can never confirm that it starts no agents of its own: it reports that the capability exists and reports nothing about whether it is switched off. No probe can close that, because there is nothing on the other side to read.

Claude Code closes it. Its startup record names the exact tool set the session loaded, the agent-dispatch tool is absent, and absence in a list that was read is evidence rather than silence. It scores 8 of 8, nothing degraded — and has never shipped a line of real work.

So a person who specifically needs the no-unaccounted-agents guarantee has a checkable reason to prefer Claude Code, and a person who needs proven throughput has a reason to prefer Codex. That is the honest slide: two columns, one table, no winner. Codex's last full probe predates two of these capabilities; its says which model spent what is determinable from its output format without a run, and its leaves the change for you follows from the same worktree discipline every shipped run used.

The agent that graded its own homework

A worker was told to build a command-line interface, and built one with the wrong argument shape.

It then wrote the tests for it — tests that described the interface it had actually built — and its own suite passed clean.

It was caught because the check that mattered was not its to write: the planner had authored an independent executable check, stored in the root contract outside the worker's reach, and it runs before the worker's own tests in a fresh tree.

The regression test for this reproduces the wrong interface with green self-authored tests, has those tests try to overwrite the repository's validator, and still records the contract check failing first. A contract forged inside the worker's own tree has zero influence. This is the demo's emotional beat: the failure mode is not an agent that breaks, it is an agent that succeeds convincingly at the wrong thing.
