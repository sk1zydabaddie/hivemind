## Historical records — not competing current instructions

- [State archive](archive/STATE-2026-09-04.md) and
  [design archive](../desktop/archive/DESIGN-NOTES-2026-09-04.md): unabridged
  pre-consolidation documents, with preserved-content hashes.
- [Remediation program](REMEDIATION-2026-08-27.md): dated execution history.
- `docs/evidence/`: original run records and build-labelled captures.
- `docs/demos/`: reproducible demo notes.

Keep new validation narratives with their work ledger/evidence. Update current
entrypoints in place; do not append a second, contradictory current status.
